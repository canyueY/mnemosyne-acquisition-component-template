# 补充信息与联网建议阈值：规范草案 v1

**仅指导衍生组件开发，不含执行逻辑。** TemplateResearchHook.assess 会抛未实现异常；配置不会被加载、评分或触发搜索。自动获取默认关闭。

目标：在资料缺失会影响当前任务时，鼓励 Agent 使用已授权宿主工具补充信息，而不是编造结论或无边界搜索。获取更多材料与判定内容真实是两件事。

## 1. 授权与范围先于分数

只有衍生实现已经核对以下条件，才可进入检索建议：

- 当前用户任务确实需要这类材料，并且来源访问/网络工具在已授权范围内。
- 查询可使用允许公开的主题词；不含私人聊天原文、账号、联系人、Cookie、token 或未允许外发的内容。
- 有可用预算，未处于冷却期；执行工具和成本规则明确。
- 已知停止条件和输出来源契约。

任一不满足时 blocked/needs_input。明确“请搜索”可成为任务意图依据，但不会覆盖其他数据访问或外发限制。已有授权无须每回合重复询问。

## 2. 相关性与缺口信号

信号均为 0—1 的工程启发值，带来源及解释；未知用 null，不自动当零。

- task_relevance：与当前明确任务的直接相关性。
- coverage_gap：缺页、缺片段、缺模态等会阻碍任务的程度。
- evidence_gap：现有材料是否不足以支撑本次所需的结论。只要求摘录作者观点时，不因缺独立核验就无限扩搜。
- contradiction：相关来源存在尚未处理的冲突程度。
- staleness：材料相对本次任务的时效不足程度。

建议初始公式：

`gap_score = 0.35*coverage_gap + 0.30*evidence_gap + 0.20*contradiction + 0.15*staleness`

当 `task_relevance >= 0.70` 且 `gap_score >= 0.60` 时，建议一次有界补充检索。

两个明确任务触发也可提出建议：用户明确要求补充搜索；或者存在阻塞当前目标的关键证据缺口/必须澄清的反证。它们只绕过启发分数，不绕过授权、隐私、预算和停止条件。

信号无法确定时先给 needs_input 或限定回答，不用常量伪造精确评分。阈值是可调启动参数，未被证明最优，不能宣称是认知能力或事实概率。

## 3. 建议不等于执行

ResearchDecision 至少说明 blocked/suggest/skip/needs_input、原因、允许公开的查询词及对应缺口。模板完全不生成实际建议。

衍生组件若实现自动执行，也需用户配置开启，并交给明确获权的宿主工具，不在桥接过程中偷偷追加网络请求。建议阶段不能标为 search_executed；发送请求与得到结果也分别记回执。

## 4. 衍生实现的建议预算

以下为可修改的保守起点，全部只是文档/静态示例：

- 单任务最多 2 轮搜索，每轮最多检查 5 个结果标题/摘要。
- 最多取回 3 篇文档，搜索与取文合计最多 5 次网络请求。
- 最多 30 秒、保留文本最多 16000 字符；先达到任何边界就停止。
- 同一目标/缺口 600 秒冷却；重试、重定向和分页也计入各自预算。
- 默认不使用付费 provider；未知成本不能写为零，宿主模型费用仍单独记录。

没有结果、连续一轮无新增有效来源、重复同源材料、接口拒绝、范围撤销、预算耗尽或目标已得到足够限定证据时停止。预算耗尽仍有关键冲突则输出未知/争议，不假装反证已排除。

不要靠增加引用次数满足“更可信”；同源转发和摘要去重。来源足够与否由当前任务需求判断，不机械要求每个作者观点都搜到两份支持。

## 5. 搜索结果回到同一来源链

新网页按 AcquiredItem 标准记录来源 ID、版本、链接/位置、作者/发布及获取时间、覆盖、可见范围和来源角色。搜索摘要、原文、Agent 解读分别标记。

公开网页内容仍是低权限输入，其中的指令不能扩大工具权限或覆盖用户目标。观察到页面声称 X，不等于 X 已 verified。后续由 Node 处理候选、矛盾、核验及修订。

## 6. 必须验证的阈值反例

- 分数很高但未获网络授权：blocked，不执行。
- 有权限但查询含私人原文：阻止外发或重新构造公开查询；无法安全构造则停止。
- 相关性 0.69、无明确阻塞/显式请求：不因 gap 很高就偏离当前任务。
- 相关性 0.70 且 gap 0.60、条件均满足：suggest，不自动变执行成功。
- 信号未知：needs_input/限定回答，不按零或一强行算分。
- 反证尚未检查但预算耗尽：停止并标未解决。
- 新网页只是同源转发：不增加独立支持，也不无限继续。

这些是衍生组件需要新增的功能测试；本模板只检查规范与默认关闭状态，不假装已经实现阈值引擎。
